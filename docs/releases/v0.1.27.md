첨부한 `gnuboard5-nextjs-v0.1.27.zip` 을 그누보드5 루트(`common.php` 가 있는 폴더)에 풀고, zip 안의 `INSTALL.md` 를 따라 주세요. GitHub 가 자동으로 만드는 Source code 압축은 설치용이 아닙니다.

## 새 기능

- **회원정보 찾기 화면을 그누보드 화면처럼** — `/forgot-password` 가 그누보드 `bbs/password_lost.php` 와 같은 모양과 입력이 됐습니다. 경로 표시 · "회원정보 찾기" 제목 · 오른쪽 사이드바와 함께, "이메일로 찾기" 카드에 **E-mail 주소와 자동등록방지만** 넣고 "인증메일 보내기"를 누릅니다(아이디 칸은 없앴습니다). "본인인증으로 찾기" 카드는 관리자 › 환경설정 › 기본환경설정에서 본인확인과 "회원정보 찾기"를 켠 사이트에만 나옵니다.
  - API `POST /api/v1/auth/password-reset`(`step=request`)이 아이디 없이 `mb_email` 과 `captcha_key` 를 받습니다. 그누보드와 같은 규칙으로 그 이메일 회원이 정확히 한 명일 때만 보내고, 탈퇴 · 차단 회원과 최고관리자는 빼며, 찾았든 못 찾았든 같은 안내를 돌려줍니다. 보내는 것은 지금처럼 비밀번호를 다시 정하는 링크입니다.
  - 아이디 + 이메일로 보내는 방식(앱)은 그대로입니다.
- **관리자 › 환경설정 › 알림 설정 현황** — 회원이 앱 · 웹의 알림 설정에서 항목별 푸시를 어떻게 켜고 껐는지 봅니다(최고관리자만, 읽기 전용). 항목별 끈 회원 수와 받는 비율, 푸시 기기 수, 회원 목록(보기 · 끈 항목 필터, 아이디 · 닉네임 검색).
- **외부 SMTP 로그인으로 메일 보내기** — 서버에 메일 프로그램이 없어도 네이버 · Gmail 같은 SMTP 계정으로 그누보드 메일(비밀번호 찾기 등)을 보낼 수 있습니다. `api/.env` 에 `G5_SMTP_AUTH_HOST` · `G5_SMTP_AUTH_PORT` · `G5_SMTP_AUTH_SECURE` · `G5_SMTP_AUTH_USER` · `G5_SMTP_AUTH_PASS` 를 넣으면 켜집니다(예시는 `api/env.example`). 넣지 않으면 예전과 같습니다. 보내는 사람은 그 계정으로 바뀌고, 원래 보낸 사람은 회신 주소(Reply-To)로 남습니다.

## 고친 것 · 바뀐 것

- **그누보드 웹 게시판에서 단 댓글 알림** — 앱 · 새 화면에서 단 댓글처럼 `[게시판] "글 제목…"의 새 댓글` / `닉네임: 내용` 문구로 보냅니다. 웹에서 단 **답글** 도 원래 댓글을 쓴 사람에게 알림이 가고, 비밀 답글이면 내용을 가립니다.
- **알림 현황의 발송 큐** — 각 푸시가 어떤 제목 · 내용으로 나갔는지 보이게 했습니다(그동안 알림함에 남는 알림은 큐 칸이 비어 보였습니다).
