## 고친 것

- **매뉴얼 장 순서를 그대로 저장해도 게시판 목록 순서가 바뀌던 것** — v0.1.24 의 장 순서 저장(관리자 › 환경설정 › 테마 화면 설정 › 순서)은 게시판 목록에서 여러 부(분류)의 글이 섞여 있는 매뉴얼에서, 번호를 바꾸지 않고 저장만 해도 게시판 목록 순서를 부별로 다시 세웠습니다. 매뉴얼 목차는 그대로였지만 게시판 목록의 글 순서가 달라졌습니다. 이제 부마다 그 부의 장들끼리만 순서를 나눠 주므로, 그대로 저장하면 아무것도 바뀌지 않고 다른 부의 장은 움직이지 않습니다.

## 업데이트할 때

1. 파일과 DB 를 백업합니다.
2. zip 을 같은 그누보드 루트에 덮어 풀고 `/api/v1/status` 에서 `schema.ok` 가 `true` 인지 봅니다(새 표는 없습니다).
3. 바뀐 파일은 `plugin/webapp/theme-settings/chapters.php` 하나입니다(그 밖에는 handbook 검사 파일).

v0.1.24 에서 장 순서를 저장해 게시판 목록 순서가 바뀌었다면, 이 판으로 올린 뒤 그 매뉴얼의 장 순서 화면에서 원하는 차례로 한 번 더 저장하세요. 설명서: https://gnuboard5-apps-manual.vercel.app/ — 3권 「매뉴얼 테마(handbook) 꾸미기」.
