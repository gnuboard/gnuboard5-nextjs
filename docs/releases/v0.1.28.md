첨부한 `gnuboard5-nextjs-v0.1.28.zip` 을 그누보드5 루트(`common.php` 가 있는 폴더)에 풀고, zip 안의 `INSTALL.md` 를 따라 주세요. GitHub 가 자동으로 만드는 Source code 압축은 설치용이 아닙니다.

## 새 기능

- **웹 에디터 사진 여러 장 한꺼번에 올리기** — 글 · 댓글 · 상품 후기 · 상품 문의 · 1:1 문의의 웹 에디터에서 사진을 여러 장 골라 한 번에 넣습니다.
- **에디터 사진 정리** — 웹 에디터로 올린 사진은 먼저 `data/tmp/editor_upload/` 에 두었다가, 글을 저장할 때 `data/editor/<년월>/` 로 옮겨 그 글에 붙입니다. 글 · 댓글 · 후기 · 문의를 지우면 그 글에 붙은 사진도 함께 지웁니다.
  - 저장하지 않고 떠난 임시 사진은 `WEBAPP_EDITOR_TMP_KEEP_DAYS`(기본 3일) 뒤에, 관리자 화면에서 게시판 · 상품을 통째로 지워 원래 글이 없어진 사진은 `WEBAPP_EDITOR_ORPHAN_GRACE_DAYS`(기본 1일) 뒤에 정리 크론 · 유지보수 비컨이 지웁니다. 0 이면 그 단계를 끕니다.
  - 사진 대장 표 `g5_editor_image` 가 새로 생깁니다(아래 "업데이트할 때").
  - 앱에서 바로 올린 사진, 복사된 글이 함께 쓰는 사진은 저절로 지우지 않습니다.
- **상품 후기 · 문의 작성 창을 넓고 높게** — 데스크톱에서 창 너비가 760px(큰 화면)까지 넓어지고, 내용 칸이 300px 높이로 커졌습니다. 별점은 "평점 · 별 다섯 개 · 이름" 한 줄로 줄여 내용에 자리를 내줍니다. 폰에서는 아래에서 올라오는 시트 그대로입니다.
- **앱 버전 정책을 `api/.env` 에서** — `GET /v1/settings` 가 `G5_APP_MIN_VERSION` · `G5_APP_LATEST_VERSION` · `G5_APP_STORE_URL_ANDROID` · `G5_APP_STORE_URL_IOS` · `G5_APP_FORCE_UPDATE_MESSAGE` 를 `api/.env`(또는 환경변수)에서 코드 기본값보다 먼저 읽습니다. 스토어에 새 버전을 올린 뒤 `.env` 한 줄만 고치면 됩니다. 형식이 틀린 값은 무시하고, `?app=<패키지명>` 의 앱별 값은 여전히 이 값보다 먼저입니다(예시는 `api/env.example`).
- **앱 본인인증으로 비밀번호 재설정** — `POST /api/v1/auth/password-reset` 이 앱 본인인증 화면이 서명한 `cert_token` 도 받습니다(웹의 같은 세션 `cert_no` 방식은 그대로).

## 업데이트할 때

1. 파일과 DB 를 백업합니다.
2. zip 을 같은 그누보드 루트에 덮어 풀고 `/api/v1/status` 에서 `schema.ok` 가 `true` 인지 봅니다. 새 표 `g5_editor_image` 는 다음 요청 때 저절로 만들어집니다(`schema.installed` 에 `webapp_admin_dbupgrade`). 만들어지지 않으면 관리자 › DB 업그레이드(`/adm/dbupgrade.php`)를 한 번 실행하세요.
3. 화면을 바꿨으므로 쓰는 Next.js 테마를 다시 올리면 됩니다(zip 의 `theme/<테마>/app/` 이 덮입니다). 내 테마를 쓰면 새 소스를 합쳐 다시 빌드하세요.
