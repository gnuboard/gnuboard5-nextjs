첨부한 `gnuboard5-nextjs-v0.1.24.zip` 을 그누보드5 루트(`common.php` 가 있는 폴더)에 풀고, zip 안의 `INSTALL.md` 를 따라 주세요. GitHub 가 자동으로 만드는 Source code 압축은 설치용이 아닙니다.

## 새로 들어온 것

- **매뉴얼 장 순서를 관리자에서** — 관리자 › 환경설정 › 테마 화면 설정의 매뉴얼 목록에서 "순서"를 누르면 그 매뉴얼의 장 목록이 나옵니다. 번호를 매겨 저장하면 그 순서가 됩니다(게시판 목록 순서도 같이 바뀌고, 답글 · 댓글은 원글을 따라 움직입니다). 새로 쓴 글은 맨 앞에 붙으니 쓴 뒤 여기서 자리를 정하세요.
- **handbook 첫 화면부터 설정대로** — 그누보드에 설치한 handbook 이 처음 그려질 때부터 저장한 문구와 화면별 사이드바 설정을 씁니다. 기본 문구가 잠깐 보였다 바뀌거나 왼쪽 열이 사라지며 본문이 밀리던 것이 없어졌고, 매뉴얼 목록이 들어올 자리도 미리 잡아 둡니다.
- **Vercel 등 Next 서버 화면** — 첫 화면 제목 · 설명과 사이트 설명도 테마 화면 설정의 문구를 씁니다.

## 업데이트할 때

1. 파일과 DB 를 백업합니다.
2. zip 을 같은 그누보드 루트에 덮어 풀고 `/api/v1/status` 에서 `schema.ok` 가 `true` 인지 봅니다(새 표는 없습니다).
3. handbook 을 쓴다면 `theme/handbook/app` 폴더는 지우고 새로 넣는 편이 깔끔합니다(예전 빌드 파일이 남지 않게).

테마 화면 설정 메뉴가 없거나 빈 화면이면 v0.1.23 보다 오래된 판입니다. 설명서: https://gnuboard5-apps-manual.vercel.app/ — 3권 「매뉴얼 테마(handbook) 꾸미기」.
