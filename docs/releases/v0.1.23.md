첨부한 `gnuboard5-nextjs-v0.1.23.zip` 을 그누보드5 루트(`common.php` 가 있는 폴더)에 풀고, zip 안의 `INSTALL.md` 를 따라 주세요. GitHub 가 자동으로 만드는 Source code 압축은 설치용이 아닙니다.

## 새로 들어온 것

- **매뉴얼 테마 handbook ("Next.js Handbook")** — zip 에 `theme/nextjs_default` 와 함께 `theme/handbook` 이 들어 있습니다. 관리자 › 환경설정 › 테마설정에서 하나를 고릅니다. 게시판 그룹 하나가 매뉴얼 묶음, 게시판이 권, 게시판 분류가 부, 글이 장이 됩니다.
- **테마 화면 설정** — handbook 을 적용하면 관리자 › 환경설정 › 테마 화면 설정이 생깁니다. 매뉴얼 그룹, 매뉴얼 순서 · 이름 · 안내 문구, 화면별 왼쪽 사이드바, 사이트 문구(로고 · 첫 화면 · 바닥글)를 정하며 다시 빌드할 필요가 없습니다. 새 표 `g5_theme_setting` 은 API 가 처음 호출될 때 스스로 만듭니다.
- **쌓이는 표를 크론 없이 정리** — 로그인 유지 토큰 · 소셜 가입 입장권 · 기기 IP · 알림 · 푸시 표를 하루 한 번 나눠 정리합니다(크론이 없는 호스팅도). 정리에 쓰는 인덱스를 더했습니다 — 아주 큰 표는 `/adm/dbupgrade.php` 에서 더합니다.
- **앱 기본값 중립** — 앱을 설정하지 않은 사이트에서 엉뚱한 "새 버전" 알림이나 앱 열기 링크가 나오지 않습니다.

## 고친 것

- 사이트 제목에 `$1` 이나 끝의 `\` 가 있으면 화면 설정 스크립트가 깨지던 것(세 테마 공통).
- handbook 탭 제목이 늘 "매뉴얼" 이던 것 — 이제 기본환경설정의 홈페이지 제목을 씁니다.
- 장바구니 · 주문서 표 머리 글자 대비(WCAG AA).
- 탈퇴 · 차단 회원의 공개 키로 아이디를 찾을 수 있던 것.

## 업데이트할 때

1. 파일과 DB 를 백업합니다.
2. zip 을 같은 그누보드 루트에 덮어 풀고 `/api/v1/status` 에서 `schema.ok` 가 `true` 인지 봅니다.
3. Apache/LiteSpeed 는 쓰는 테마를 관리자 › 테마설정에서 한 번 다시 적용합니다. nginx 는 `nextjs-install/nginx/` 의 예시(handbook 용 파일이 새로 있음)를 확인합니다.
