첨부한 `gnuboard5-nextjs-v0.1.26.zip` 을 그누보드5 루트(`common.php` 가 있는 폴더)에 풀고, zip 안의 `INSTALL.md` 를 따라 주세요. GitHub 가 자동으로 만드는 Source code 압축은 설치용이 아닙니다.

## 새 기능

- **매뉴얼 테마(handbook) — 화면에서 바로 화면 설정** — 최고관리자로 로그인하면 사이트 위쪽 바에 "화면 설정" 단추와, 첫 화면 · 바닥글 · 사이드바 옆에 연필이 생깁니다. 누르면 편집 창(사이트 문구 · 사이드바 · 매뉴얼 · 장 순서)이 열리고, 저장하면 새로고침 없이 바로 바뀝니다. 손님과 일반 회원의 화면은 그대로이고, 편집 창 코드는 최고관리자에게만 따로 내려갑니다. 관리자 › 환경설정 › 테마 화면 설정과 같은 값을 저장합니다.
  - 새 API: `GET/PUT /api/v1/theme-settings`, `GET/PUT /api/v1/theme-settings/chapters/{bo_table}` (최고관리자만). 다른 사람이 그사이 저장했으면 덮지 않고 409 로 알립니다.
- **게시글 수정 이력과 비교** — 매뉴얼 그룹(`manual`, `G5_POST_HISTORY_GROUP_ID` 로 바꿀 수 있음) 게시판의 글은 고칠 때마다 이전 내용이 남고, 관리자는 글 보기의 "게시글 수정 이력 보기" 단추로 두 판을 나란히 비교할 수 있습니다. 지우거나 옮긴 글의 이력은 관리자 › 게시판관리 › **게시글 이력 보관함** 에서 봅니다.
- **앱용 첨부 파일 받기 API** — `GET /api/v1/board-file-downloads/{bo_table}/{wr_id}/{bf_no}`. 토큰(Bearer)으로 로그인하는 앱이 첨부를 받을 수 있습니다. 글 읽기 권한 · 다운로드 레벨 · 다운로드 포인트(글당 한 번)를 `bbs/download.php` 와 같이 검사하고, 큰 파일은 이어받기(Range)를 지원합니다.
- **앱 공통 법적 문서** — `plugin/webapp/legal/` 에 개인정보처리방침 · 이용약관 · 계정 삭제 안내를 두었습니다. 서비스 이름과 운영자 정보는 사이트 설정(홈페이지 제목, 쇼핑몰 사업자 정보)에서 읽고, `/api/v1/settings` 의 `legal_urls` 가 이 문서를 가리킵니다. 사이트가 따로 둔 문서가 있으면 `api/.env` 의 `G5_LEGAL_PRIVACY_URL` · `G5_LEGAL_TERMS_URL` · `G5_LEGAL_ACCOUNT_DELETION_URL` 로 바꿀 수 있습니다.
- **푸시 전달 결과 확인** — 푸시를 보낸 뒤 15분쯤 지나 Expo 에 실제 전달 결과를 묻고, 기기에서 지워진 토큰은 정리합니다. 앱을 다시 설치하거나 다시 로그인해 같은 토큰을 다시 등록했으면 지우지 않습니다. (푸시 큐 크론 `plugin/webapp/cron/process_push_queue.php` 이 함께 합니다.)

## 고친 것 · 바뀐 것

- **댓글 · 답글 알림 문구** — 알림만 보고 어느 게시판의 어떤 글 · 댓글인지 알 수 있게 바꿨습니다. 예: `[자유게시판] "글 제목…"의 새 댓글` / `닉네임: 댓글 내용`. **비밀 답글** 은 원래 댓글을 쓴 사람에게 내용 대신 "비밀 답글입니다." 로 보냅니다(그 사람은 비밀 답글을 볼 수 없는 사람이라서).
- **앱 소셜 로그인 콜백 주소를 더 좁게 검사** — 앱으로 돌아가는 주소는 `<앱 스킴>://social-callback` 꼴만 받습니다(다른 경로 · 사용자 정보 · 포트가 붙은 주소는 거절). 앱이 이 꼴을 쓰지 않으면 소셜 로그인이 막히니 확인해 주세요.
- **탈퇴 회원의 1:1 문의** — 탈퇴할 때 1:1 문의의 이름 · 이메일 · 휴대폰 · IP 도 익명으로 바꿉니다.
- **로그인 확인이 늦을 때 화면이 멈추던 것** — 서버에서 로그인 상태를 확인하는 요청(`/auth/me`)에 3초 시간 제한을 두었습니다. API 가 느리면 일단 비로그인으로 그리고, 화면이 뜬 뒤 로그인 상태를 다시 맞춥니다.
- **기본 테마** — 첫 화면의 빈 게시판 칸과 쇼핑몰 배너 모양을 다듬었습니다.
- **매뉴얼 테마 화면 설정 저장을 더 안전하게** — 관리자 화면에서도 바꾼 게시판 칸만 저장해, 창을 연 사이 다른 곳에서 고친 게시판 제목 · 순서를 되돌리지 않습니다.

## 업데이트할 때

1. 파일과 DB 를 백업합니다.
2. zip 을 같은 그누보드 루트에 덮어 풀고 `/api/v1/status` 에서 `schema.ok` 가 `true` 인지 봅니다. 새 표(게시글 이력)와 칸(푸시 전달 결과)은 API 가 스스로 만듭니다. `false` 면 최고관리자로 `/adm/dbupgrade.php` 를 한 번 엽니다.
3. 매뉴얼 테마(handbook)를 쓰면 테마를 다시 적용하지 않아도 됩니다. 화면 설정 편집 창은 최고관리자로 로그인하면 바로 보입니다.
